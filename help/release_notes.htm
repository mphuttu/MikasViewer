Release Notes

MikasViewer 1.0

Initial release of the desktop image viewer with Explorer-style browsing, fit-to-window image display, zoom and pan controls, WebP support through WIC, integrated print and print preview, and a built-in CHM help system.

Highlights

  • Tree-based browsing for drives, folders, and image files
  • Mouse-wheel zoom with cursor-anchored behavior
  • Drag-to-pan for large images
  • High-quality rendering with GDI+ interpolation
  • Print and preview support
  • Full CHM help documentation
Tip: Review the help pages for workflow recommendations, keyboard shortcuts, and troubleshooting guidance.
