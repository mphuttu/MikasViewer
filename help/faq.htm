Frequently Asked Questions

Does MikasViewer support all image types?

It supports the major desktop image formats most commonly used on Windows: JPEG, PNG, BMP, GIF, TIFF, and WebP.

Can I print an image?

Yes. Use the File menu or the keyboard shortcut Ctrl+P to print the current image. Print preview is also available.

Does the program enlarge images beyond 100% on load?

No. Images are fit to the window at a maximum of 100% of their actual size when first opened.

Why does the image appear dark around the edges?

The viewer uses a dark background for comfortable viewing and to frame the image while panning or zooming.

Why are some WebP files missing?

The Windows codec may not be installed. Install the WebP Image Extensions app on Windows 10 or use a newer Windows version.

Where can I find more help?

Use the built-in help system or review the content in the help index. The help pages cover browsing, printing, zooming, troubleshooting, and technical notes.
