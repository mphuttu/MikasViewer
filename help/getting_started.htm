Getting Started

Installation

Install MikasViewer by running the setup package or by extracting the program files to a folder on your system. The application targets Windows 10 and later and uses the Microsoft Visual C++ 2015–2022 x64 runtime.

First Launch

  1. Start MikasViewer from the Start menu or a desktop shortcut.
  2. Wait for the folder tree to populate the available drives and folders.
  3. Expand a drive or folder to view the images contained within.
  4. Click a file to open it in the main viewing area.

Quick Start Workflow

A typical use case is: open the root folder of a photo library, expand a subfolder, click the first image in the folder, then use the mouse wheel to inspect details. Use drag-to-pan for larger images and print the file when needed.

Tip: The folder tree loads content on demand, so large disks remain responsive while you browse.
