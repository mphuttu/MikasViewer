Browsing and Viewing Images

Manage and View Modes

Use the Manage and View toolbar buttons to switch between browsing and inspecting the current image. Manage shows the folder tree, thumbnail list, and image preview. View hides the browsing panes. The current selection is retained when switching modes.

The Folder Tree

The left panel shows an Explorer-style folder tree. All logical drives on your computer are listed at the root level with their Windows display names (for example, Windows (C:)).

  • Click the arrow or + next to a drive or folder to expand it. Subfolders and image files are loaded on demand.
  • Image files are shown directly inside folders — you do not need to open a separate file dialog.

Opening an Image

ActionResult
Click a folder Lists supported images and previews the first image by name. An empty folder clears the preview.
Click an image file in the tree or a thumbnail Displays that image immediately.
Double-click a thumbnailOpens View mode.

Thumbnails are provided by Windows. If a thumbnail is unavailable, the filename remains in the list and can still be selected.

Navigating Images

In Manage or View, click the image or thumbnail list and use the Left and Right arrow keys to select the previous or next image in the current folder. Home selects the first image and End selects the last. Images follow the thumbnail list order and navigation stops at either end of the list.

When there is enough space beside the image, click the left or right arrow to open the adjacent image. An arrow is not shown when there is no image in that direction. The folder tree retains its normal keyboard navigation when focused.

Slideshow

Choose Slideshow → Start to display images from the selected image onward in the current folder's thumbnail order. The application switches to View mode. The Slideshow menu remains available there.

Use Interval to choose 2, 5, 10, or 30 seconds; the default is 5 seconds. Repeat is enabled by default and continues from the first image after the last. Turn it off to stop at the last image. Settings last until the application closes and can be changed during playback.

Use Slideshow → Stop or press Esc in the image view to stop, leaving the current image visible. Switching to Manage mode, opening another folder, printing, or an image loading error also stops playback. Manual image navigation during playback restarts the interval.

Image Display

When an image is opened it is automatically scaled to fit the window (up to 100 % of its original size). If the image is smaller than the window, it is shown at its actual size and centered.

The window title bar shows the filename of the currently displayed image.

Tip: Resize the application window — the image recenters itself automatically.
