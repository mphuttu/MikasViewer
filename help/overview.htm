MikasViewer Help

Welcome to MikasViewer, a fast, lightweight Windows image viewer designed for quick browsing, zooming, and printing of common image files.

Overview

MikasViewer offers a simple desktop experience built around an Explorer-style tree view. Browse your drives and folders, discover images in-place, and open files directly from the tree without a separate file picker.

  • Browse folders and image files from a familiar folder tree.
  • Load large directories on demand for responsive viewing.
  • View images in a centered fit-to-window layout.
  • Zoom and pan with the mouse wheel and drag gestures.
  • Print or print-preview the current image.

Key Features

  • Explorer-style navigation with logical drives and shell icons.
  • Lazy folder loading to keep large trees responsive.
  • Direct image browsing using image entries in the tree.
  • Fit-to-window display with automatic centering.
  • Mouse wheel zoom anchored to the cursor.
  • Print and print preview for the current image.
  • Built-in CHM help system with F1 support.

Audience

This application is intended for users who want a straightforward image viewer for everyday browsing, quick comparisons, and basic printing on Windows 10 or later.

Quick Start

  1. Open the application and expand a drive or folder in the tree.
  2. Click a folder to display the first image it contains.
  3. Click an image thumbnail entry to open the selected file.
  4. Use the mouse wheel to zoom and drag to pan.
  5. Choose File → Print or File → Print Preview when ready.
Tip: The current image filename is always shown in the main window title bar.
