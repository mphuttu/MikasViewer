Application Options

MikasViewer is intentionally lightweight and does not include a large settings dialog. Most behavior is controlled by the default viewer behavior, the Windows theme, and the current window size.

Default Image Behavior

  • Images open in a centered fit-to-window layout.
  • Zoom is adjusted automatically on first load.
  • Scroll bars appear only when an image exceeds the current window size.

Display Behavior

  • Images are shown on a dark gray background for comfortable viewing.
  • High-quality bicubic interpolation is used for scaling.
  • The title bar shows the current filename to make multi-image workflows easier.
Note: The application follows standard Windows behavior for dialogs, printing, and menu commands. No custom keyboard mappings are overridden.
