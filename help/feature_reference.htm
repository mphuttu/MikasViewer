Feature Reference

Folder Tree Navigation

The left panel contains an Explorer-style folder tree. Logical drives are shown at the root and each branch loads subfolders on demand.

  • Click a folder to list its supported images and preview the first image by name.
  • Click an image file to open it directly.
  • Expand or collapse directories using the standard tree control behavior.

Manage, View and Slideshow

Manage shows the folder tree, thumbnail list and image preview. View hides the browsing panes for image inspection. Select Slideshow → Start to play the current folder in View mode. The Slideshow menu lets you set the interval and repeat behavior; use Stop or Esc to end playback.

With the image or thumbnail list focused, use Left and Right for adjacent images, Home for the first image and End for the last. See Browsing and Viewing Images for details.

Zoom and Pan

Zoom is controlled with the mouse wheel and is anchored to the cursor position. The range is 5% to 2000%. Pan is done with left-click and drag, or by using the scroll bars when visible.

  • Scroll up: zoom in.
  • Scroll down: zoom out.
  • Click + drag: pan large images.

Print and Preview

Use File → Print or Ctrl+P to print the current image. Use File → Print Preview to review the result before sending it to a printer.

The image is centered and scaled to fit the available printable area while preserving aspect ratio. A small margin is left around the edges.

Supported Formats

MikasViewer supports JPEG, PNG, BMP, GIF, TIFF, and WebP. WebP requires additional codec support on Windows 10, while Windows 11 includes it by default.

Tips and Limitations

  • Large files may take a moment to render the first time.
  • Only the first frame of GIF files is displayed.
  • The application is optimized for single-image viewing rather than full asset management.
Tip: Use the file tree to keep your workflow visual and quick — you can browse without opening a separate dialog window.
