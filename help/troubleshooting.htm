Troubleshooting

Common Problems

Help file does not open

Confirm that MikasViewer.chm is present next to the main executable. If the file is missing, rebuild the CHM help project or reinstall the application package.

Images do not display

Ensure the file is in a supported format and the extension matches the actual contents. If the viewer does not open a file, try a different image editor or confirm that the file is not corrupted.

WebP files fail to open

On Windows 10, install WebP Image Extensions. On Windows 11, the codec is typically available by default.

Print is disabled

Print and print preview are available only while an image is loaded. Select a valid image first, then try again.

Recovery Procedures

  • Restart the application after installing missing runtime components.
  • Rebuild the CHM help file if the help window fails to open.
  • Reinstall the app if files or shortcuts are missing.
Note: If the application does not start, verify that the Visual C++ 2015–2022 x64 redistributable is installed.
