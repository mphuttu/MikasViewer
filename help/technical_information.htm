Technical Information

Supported Operating Systems

MikasViewer targets Windows 10 and later operating systems.

Requirements

  • Windows 10 or later
  • Visual C++ 2015–2022 x64 redistributable
  • Modern desktop environment with MFC support

Architecture Notes

The application is built as a native 64-bit Windows desktop program using MFC, GDI+, and WIC for image decoding. The file tree is implemented as an Explorer-style tree control and the image viewport uses double-buffered drawing for smooth presentation.

File Formats

The app recognizes image files by extension and loads them as needed. Supported formats include JPEG, PNG, BMP, GIF, TIFF, and WebP.
